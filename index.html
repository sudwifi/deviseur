Comment ça fonctionne :
Le bouton "→ Axonaut" retrouve l'entreprise (par son nom), crée une opportunité dans le pipe ci-dessus puis un devis rattaché à cette opportunité, avec toutes les lignes du chiffrage (matériel, MO, Adipsys). Le devis suit ainsi sa progression dans le pipe.

Alternative sans API : Si votre réseau bloque les appels directs, utilisez Make/N8N avec un webhook — je peux vous fournir le modèle.
